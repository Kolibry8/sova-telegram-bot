# 🦉 Сова — Добрый помощник Telegram-группы

Бот, который поддерживает позитивную и добродушную атмосферу в вашей Telegram-группе.

## Возможности

- 💬 Поддерживает беседы и отвечает на сообщения
- 🦉 Отвечает тепло и дружелюбно
- 💜 Утешает, когда грустно
- 🎉 Радуется, когда весело
- 🤖 Использует Google Gemini для умных ответов (бесплатный тариф)
- 📝 Если Gemini недоступен — отвечает встроенными шаблонами

## Быстрый старт

### 1. Создай бота в Telegram

1. Открой [@BotFather](https://t.me/BotFather) в Telegram
2. Отправь `/newbot`
3. Придумай имя и username для бота
4. Скопируй полученный токен

### 2. Установи зависимости

```bash
pip install -r requirements.txt
```

### 3. Настрой переменные окружения

Скопируй `.env.example` в `.env` и заполни:

```bash
cp .env.example .env
```

Добавь токены в `.env`:
```
TELEGRAM_TOKEN=твой_токен_от_BotFather
GEMINI_API_KEY=ключ_с_aistudio.google.com/apikey
```

### 4. Запусти бота

```bash
python bot.py
```

### 5. Добавь в группу

1. Зайди в настройки своей группы в Telegram
2. Добавь бота как участника
3. Сделай бота администратором (чтобы он мог читать сообщения)

## Хостинг (бесплатно на Render)

1. На [render.com](https://render.com) → New → Blueprint → выбрать этот репозиторий (настройки берутся из `render.yaml`)
2. Вставить `TELEGRAM_TOKEN` и `GEMINI_API_KEY`
3. В [UptimeRobot](https://uptimerobot.com) добавить проверку адреса сервиса каждые 5 минут — иначе бесплатный Render усыпит бота

## Настройка характера бота

Измени `SYSTEM_PROMPT` в `.env` или `config.py`, чтобы задать свой характер:

```
SYSTEM_PROMPT=Ты — Сова, добрый помощник...
```

## Структура проекта

```
bot.py          — основной файл бота
config.py       — конфигурация и промпт
.env.example    — пример переменных окружения
requirements.txt — зависимости
render.yaml     — настройки хостинга Render
```
